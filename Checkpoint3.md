# Problem

The third checkpoint requires the development of an algorithm to identify slow conduction fields from the traces of given 20 unipolar signals. 

The algorithm must return the following outputs:

1. **slow conduction fields evaluated on a 16x16 grid** 

The algorithm must be uploaded into the group's branch of the main repository. The implementation should follow the signature proposed in the checkpoint3.ipynb file. 

## Evaluation

The checkpoint's evaluation will be performed on a test dataset, not at your disposal. Your algorithm performance would allow for a maximum of 6 points. The evaluation metric will consider the accuracy and the efficiency of the annotation algorithm.
The group of students implementing the algorithm with the best efficiency-accuracy balance will receive a bonus point. 

## Dataset

The dataset comprises a set of 20 unipolar traces acquired in 25 different scenarios. Impulse sites and anisotropy ratios have been provided for these cases.
